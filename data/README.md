# Data provenance

`Concrete.xls` contains the 1,030 observations and nine variables from the UCI Machine Learning Repository's **Concrete Compressive Strength** dataset. A value-by-value comparison against UCI's `Concrete_Data.xls` was completed on 26 September 2026; the tabular contents are identical.

- Creator: I-Cheng Yeh
- Repository: UCI Machine Learning Repository
- DOI: https://doi.org/10.24432/C5PK67
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Retrieved for verification: 26 September 2026

The eight inputs describe mixture components and age. The target is compressive strength in MPa. UCI reports no missing values.

The local workbook has a different file hash from UCI's workbook because the binary container differs. The loaded column names, shape and numeric values match exactly.
